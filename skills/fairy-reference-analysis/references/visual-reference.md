# 视觉与 UI 参考协议

## 采集来源

优先级：

1. 真实运行界面截图和录屏
2. DOM / 可访问性树（网站、Electron、网页游戏）
3. 公开宣传图和官方视频
4. 未加密且授权范围内的 UI 文件

加密资产不要为了取得参考而解密。运行时看到的设计已经足够提炼布局、色彩和交互；需要素材时让用户提供授权文件或替换为原创资产。

## 状态矩阵

至少采集以下状态：

- 主界面、战斗/核心操作界面、设置页、暂停页
- 默认、悬停、按下、选中、禁用、加载、错误
- 弹窗打开前后、菜单展开/收起、长列表滚动
- 空状态、首次使用、满级/满资源等边界状态
- 不同窗口比例或分辨率

每个状态记录：

```text
URL / 场景：
分辨率：
截图：
交互动作：
观察事实：
推断：
```

## 设计令牌提取

输出至少包含：

```json
{
  "layout": {"columns": [], "spacing_scale": [], "safe_area": []},
  "color": {"background": [], "surface": [], "text": [], "accent": [], "danger": []},
  "type": {"family": [], "size": [], "weight": [], "line_height": []},
  "shape": {"radius": [], "border": [], "shadow": [], "clip": []},
  "motion": {"duration_ms": [], "easing": [], "transition": []},
  "density": {"row_height": [], "control_size": [], "padding": []}
}
```

不要只写“科技风”“复古风”。必须给出可实现的层级、比例、间距、状态和交互。

|---|---|---|---|---|---|---|
| 主按钮 | 图标+文本 | default/hover/pressed/disabled | ... | ... | ... | ... |

## 禁止事项

- 不把截图直接当作产品背景图或切图使用。
- 不复制目标字体、图标集、人物立绘、UI 皮肤文件。
- 不绕过加密图片/音频扩展名去读取原始素材。
- 不把“看起来相似”当作精确测量；无法测量时明确标注为推断。
