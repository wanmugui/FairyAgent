# 人体测量参考与三视图用法

> 高度数据来自 `blockout-character.py` 实测：搭出的 1.70m 人形包围盒 `z[0.004..1.651]`，
> 像素检测到颈部收窄 70px、腰部 108px，三视角经 vision 确认为可辨人形。

## 成年人标准尺寸（1 单位 = 1 米，身高 1.70）

| 部位 | 高度 (m) | 占身高 |
|---|---|---|
| 头顶 | 1.655 | 0.974 |
| 下巴 | 1.432 | 0.842 |
| 眼高 | 0.940 | 0.553 |
| 肩 | 1.400 | 0.824 |
| 胸腔中心 | 1.270 | 0.747 |
| 腕 | 0.815 | 0.479 |
| 腰 | 1.060 | 0.624 |
| 胯 | 0.900 | 0.529 |
| 膝 | 0.485 | 0.285 |
| 踝 | 0.090 | 0.053 |
| 脚 | 0.030 | 0.018 |

**头身比**：头高 = 1.70 / 7.5 ≈ 0.227。成年人约 7.5 头身，男性约 8，二次元风格 6.5~7。

**相机必须平视眼高（0.94）**，否则透视会扭曲比例。
`blockout-character.py` 里三个机位都取 z ≈ 0.94~1.05。

## 常用宽度

| 部位 | 参考值 |
|---|---|
| 肩宽 | 0.46（约 2 个头宽） |
| 头高 | 0.227 |

**实测建模要点：肢体中心离躯干 ≤ 0.15m。**
超过这个距离，voxel remesh 时手臂/腿会与躯干不连通而被**静默删除**（见 `api-notes.md`）。

## 三视图怎么用

### 能用来做什么

- **定比例关系**：头身比、各段长度占比
- **定服装结构**：袖口在哪、裙摆多宽、配饰挂点
- **定对称性**：确认左右体块一致

### 不能用来做什么

⚠️ **不要拿三视图量尺寸。** 扩散模型出的三视图不保证正交投影下几何闭合，
透视会让比例失真。**具体数值按上面的测量表自己定**，三视图只当"大致比例"的参考。

⚠️ **三视图不等于几何闭合的参考网格。** 它是风格图，不是图纸。

### 出图后的校验

出图先检查三块是否真的对齐（头的高度一致、肩线水平、同一比例），
错位就先修图再建模——**参考图错了，模型必然错，而且后面很难发现**。

## 用法示例

```python
# 改 blockout-character.py 的常量即可调整比例
H_CHEST = 1.270   # 胸腔中心
H_WAIST = 1.060   # 腰
H_HIP   = 0.900   # 胯
H_KNEE  = 0.485   # 膝
H_FOOT  = 0.030   # 脚
```

改完必须重跑并**看图**：

```bash
/home/user/Fairy/.tools/blender/blender-4.5.14-linux-x64/blender \
  -b --factory-startup -P blockout-character.py
```

包围盒 z 下界应接近 0，上界接近 1.65（1.70m 人形）。
