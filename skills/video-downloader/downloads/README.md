# 📥 下载文件夹

**所有下载的视频和字幕都会保存在这里！**

## 📁 文件组织结构

```
downloads/
├── YouTube/              # YouTube 视频
│   ├── 频名/
│   │   ├── 视频名.mp4
│   │   ├── 视频名.zh-Hans.srt    # 中文字幕
│   │   └── 视频名.en.srt         # 英文字幕
├── bilibili/             # B站视频
│   └── UP主/
│       └── ...
└── twitter/              # Twitter视频
    └── ...
```

## 💡 使用建议

1. **定期清理** - 删除不需要的视频释放空间
2. **分类整理** - 按需创建子文件夹分类
3. **备份重要** - 重要视频建议备份到其他位置
4. **检查字幕** - 下载后检查字幕是否正确

## 🗑️ 清理命令

```bash
# 查看占用空间
du -sh *

# 删除某个平台的所有视频
rm -rf YouTube/

# 删除 7 天前的文件
find . -mtime +7 -delete
```

## 📊 当前内容

运行此命令查看下载列表：
```bash
find . -name "*.mp4" -o -name "*.srt" | sort
```
